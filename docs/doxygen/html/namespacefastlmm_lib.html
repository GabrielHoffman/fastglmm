Generalized linear model fit with IRLS

Adapted from irls_qrnewton() in https://bwlewis.github.io/GLM/ Values are mu are initialized as in R's glm(). work->residuals stores the Pearson residuals. Calls lm() on weighted working response and design matrix.

Parameters
Xdesign matrix
yresponse vector
familytype of GLM: "gaussian", "gaussian/identity", "binomial/logit", "binomial/probit", "poisson/log", "quasibinomial/logit", "quasipoisson/log", "nb", nb:x" where x is a numeric value of theta
mdlevel of model detail returned, with LEAST = 0, LOW = 1, MEDIUM = 2, HIGH = 3, MOST = 4, MAX = 5. LEAST (beta), LOW (beta, se, dispersion, rdf), MEDIUM (vcov), HIGH (pearson residuals), MOST (hatvalues), MAX (deviance residuals)
weightssample-level weights
offsetsample-level offsets
workGLMWork workspace to store intermediate results
betaInitinitial value for coefficients. If empty, use initialize() methods from GLMFamily
epsilonstopping criteria for norm between coefficient estimates compare to the previous iteration
maxitmax iterations

Negative binomial fit

Fit Poisson model, then estimate theta parameter of negative binomial. Coefficients have a small dependence on theta that is apparent with using offset, so need to iteratively estimate coefficients and theta.

Parameters
Xdesign matrix
yresponse vector
mdlevel of model detail returned, with LEAST = 0, LOW = 1, MEDIUM = 2, HIGH = 3, MOST = 4, MAX = 5. LEAST (beta), LOW (beta, se, dispersion, rdf), MEDIUM (vcov), HIGH (pearson residuals), MOST (hatvalues), MAX (deviance residuals)
weightssample-level weights
offsetsample-level offsets
doCoxReiduse Cox-Reid adjustment when estimating overdispersion for negative binomial models.
workGLMWork workspace to store intermediate results
betaInitinitial value for coefficients. If empty, use initialize() methods from GLMFamily
epsilonstopping criteria for norm between coefficient estimates compare to the previous iteration
maxitmax iterations
epsilon_nbstopping criteria for norm between coefficient estimates compare to the previous iteration in estimating theta
maxit_nbmax iterations for estimating theta
