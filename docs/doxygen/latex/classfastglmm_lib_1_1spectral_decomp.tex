\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class fastglmm\+Lib::\+spectral\+Decomp$<$ T $>$}
Class storing matrix Z, its {\itshape squared} singular values (s), left singular vectors (U), and right singular vectors (V). Z can be mat or sp\+\_\+mat. Default type is GENERAL for arbitrary matrix Z. If Z is a categorical design matrix, use a faster method with type CATEGORICAL.
