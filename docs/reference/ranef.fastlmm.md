# Extract the modes of the random effects

Extract the modes of the random effects

## Usage

``` r
# S3 method for class 'fastlmm'
ranef(object, ...)
```

## Arguments

- object:

  fitted model of class `fastlmm`

- ...:

  other args, not used

## Examples

``` r
library(MASS)

# GLMM via PQL
fit = fastglmm(y ~ trt + I(week > 2) + (1 | ID),
   family = binomial(), data = bacteria)

ranef(fit)
```
