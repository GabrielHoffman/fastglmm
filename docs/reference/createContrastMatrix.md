# Create Contrast Matrix

Create contrast matrix as array or text

## Usage

``` r
createContrastMatrix(model, hypothesis.matrix, rhs = NULL)
```

## Arguments

- model:

  model fit

- hypothesis.matrix:

  array or text indicating contrast

- rhs:

  right hand side of equation
