# Convert list to fastlmm class

Convert list to fastlmm class

## Usage

``` r
as.fastlmm(x, design, offset, method)
```

## Arguments

- x:

  list from `.fastlmm_()`

- design:

  design matrix for fixed effects

- offset:

  offset

- method:

  method used in model fit

## Value

object of class `fastlmm`
